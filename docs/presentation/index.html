El Problema

¿Por qué fallan las apps de finanzas?

La mayoría de las personas abandonan el registro de sus gastos diarios debido a la fricción de entrada y la complejidad de las interfaces:

  • ✕
    Entrada de datos lenta y engorrosa

    Escribir montos, categorías, cuentas y notas en teclados táctiles pequeños toma demasiado tiempo.

  • ✕
    Pérdida de la privacidad financiera

    Las aplicaciones en la nube analizan, guardan y a veces monetizan los datos de compras y saldos del usuario.

  • ✕
    Falta de automatización

    Pocas herramientas entienden el contexto semántico de un gasto sin que el usuario configure reglas manuales complejas.

📉

El 80% abandona

el control de presupuestos en la primera semana debido a la tediosa captura manual.

La Solución

Hablar de forma natural y registrar al instante

EG Mobile Money Assist combina la inmediatez de la voz con la categorización inteligente de Gemini AI:

  • ✓
    Cero Fricción con Registro por Voz

    Solo mantén pulsado el botón y di: "Gasté 45 dólares en la cena con amigos".

  • ✓
    Extracción Semántica Avanzada

    Gemini 1.5 Flash detecta automáticamente el tipo (Gasto), el monto ($45.00), la divisa (USD) y la categoría (Comida).

  • ✓
    Control Offline Completo

    La base de datos es local. Tú controlas tu clave de API de Gemini y tus finanzas se quedan en tu dispositivo.

Ingeniería

Clean Architecture modularizada

La aplicación utiliza un diseño desacoplado que separa la lógica de presentación de las bases de datos y los servicios de red:

📱

Capa de Presentación

UI declarativa construida en Jetpack Compose. Utiliza ViewModels con StateFlow para mantener la reactividad del estado de forma síncrona.

⚙️

Capa de Dominio

Contiene los casos de uso puros y entidades del negocio. Libre de dependencias externas para garantizar la portabilidad y facilitar test unitarios.

📦

Capa de Datos

Gestiona Room DB (SQLite local), Ktor client para comunicarse directamente con Gemini API y DataStore para configuraciones clave-valor.

Seguridad

Privacidad absoluta y control local

EG Mobile Money Assist pone el control de los datos en manos del usuario, eliminando servidores intermediarios:

  • 🔒
    Tus Claves, Tus Datos

    Configura tu clave de Gemini API localmente. Se almacena de forma encriptada en el almacenamiento seguro de Android.

  • 🔒
    Almacenamiento Local Offline-First

    Las transacciones y saldos se guardan únicamente en tu base de datos SQLite (Room) local. No se requiere cuenta ni inicio de sesión.

  • 🔒
    Exportación libre

    Exporta tu base de datos Room completa a formato CSV o haz copias de seguridad locales en un solo toque.

Offline-First

La aplicación funciona perfectamente sin internet para consultas ordinarias, requiriendo red únicamente para la llamada API a Gemini.
